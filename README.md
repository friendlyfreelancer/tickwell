# Tickwell

One Google Play listing, "Tickwell: Classic Watch Faces" (`com.friendlyfreelancer.classicfaces`,
published by Friendly Freelancer),
made of three modules:

- **`wear`**: the watch app. It plays a mechanical tick-tock each second while the screen is on,
  and it carries the watch face and installs it with
  [Watch Face Push](https://developer.android.com/training/wearables/watch-face-push) (Wear OS 6+).
- **`face`**: the watch face, built with [Watch Face Format](https://developer.android.com/training/wearables/wff)
  (declarative XML, no code). It is never uploaded on its own. Its package,
  `com.friendlyfreelancer.classicfaces.watchfacepush.classic`, follows the naming Watch Face Push
  requires.
- **`phone`**: the phone companion. It shows the styles, opens the Play listing so the user can
  install on their watch, opens the watch app remotely, and explains setup. Remote opening uses a
  Data Layer message (`/classicfaces/open`), not `RemoteActivityHelper`, which needs Google's Wear
  OS phone app and so fails with Galaxy Watches paired through Galaxy Wearable. It shares the package name and signing key with `wear`, so
  phone users count as testers in Play's closed test.

Google Play rejects a single bundle that has both a Watch Face Format face and app code, which is
why the face stays a separate, code-free APK packed inside the watch app.

## Watch face

Long-press the face → Customize:

- **Style:** Heritage, Railroad, Pilot, Dress, Quartz, Vintage, Field, Chrono, Diver.
  - Dress and Field show the date at 3, and Diver shows it at 9.
  - Vintage has a small seconds dial.
  - Chrono has working sub-dials: running seconds, a 24-hour hand and a battery gauge.
- **Hands:** Original, Blued steel, Black, Silver, Gold, Rose gold.

Every dial carries the "AJAR" mark; the name appears nowhere else. The seconds hand always ticks,
so it lines up with the tick sound. Always-on mode switches to a minimal black dial.

Keep configurations un-nested in the XML. Samsung's watch face editor crashes
(`ConcurrentModificationException`) when a configuration sits inside another one's option.
That's why hand colour is a tint (`ColorConfiguration` + `tintColor`, at most 5 colours per
option in WFF v1) and not a per-style list.

## Watch app

- **Watch face:** the system installs the bundled face along with the app. On updates,
  `UpdateReceiver` pushes the newer face. "Use Tickwell face" asks for
  `SET_PUSHED_WATCH_FACE_AS_ACTIVE` and switches to the face. The system allows that only once per
  app, so after that the app tells the user to long-press the watch face instead.
- **Tick sound:** on/off switch, volume, and a **Sync** slider that fires each tick up to 150 ms
  early to cancel speaker latency. A "Tick sound" Tile toggles it in one tap. It only ticks while
  the screen is on, and stays silent in silent mode or Do Not Disturb.
- Ticking runs as a `mediaPlayback` foreground service. Play asks you to declare this; the reason
  is "plays a ticking sound while the screen is on".
- After a reboot, open the app once to resume ticking. Android 15+ blocks media services from
  starting at boot.

## Build & install

```sh
export JAVA_HOME=~/.jdks/jbr-21.0.11
./gradlew :wear:assembleDebug :phone:assembleDebug
adb -s <watch> install wear/build/outputs/apk/debug/wear-debug.apk
adb -s <phone> install phone/build/outputs/apk/debug/phone-debug.apk
```

Building `wear` builds the release face, validates it with `tools/validator-push-cli.jar`
(Google's Watch Face Push validator, which also runs the Watch Face Format checks), and bundles it
as `assets/default_watchface.apk` with its validation token. A face that fails validation fails
the build.

Versions live in `gradle.properties`. Bump `appVersionCode` before every Play upload. The
watch app uses `1000 + appVersionCode` so its code never collides with the phone app's.

For Play: run `./gradlew :wear:bundleRelease :phone:bundleRelease` with a `keystore.properties`
file (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`) in the project root, so both
bundles and the embedded face are signed with the same release key. Upload the wear bundle to the
Wear OS track and the phone bundle to the phone track of the same app.

## Changing the designs

Dials, hands, previews, `face/src/main/res/raw/watchface.xml`, and the phone app's gallery images
and icon are generated by `tools/generate_assets.py`. The tick sounds and watch app icons are
generated by `tools/generate_tick.py`. Both need Pillow. After editing:

```sh
python3 tools/generate_assets.py
./gradlew :wear:assembleDebug   # re-validates the face
```
